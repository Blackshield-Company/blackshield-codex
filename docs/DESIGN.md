# Design notes (v0.1, early beta)

Blackshield Codex is a separate, optional plugin so that none of the five first-wave mods depends on another. It has all five as masters, adds 45 records of its own (FormIDs 0x800-0x82C, ESL-flagged), and overrides nothing.

## Records

| EditorID | Type | Purpose |
|---|---|---|

| `BCX_Enabled`, `BCX_PollSeconds`, `BCX_RenownPerOath`, `BCX_BlessingFavor`, `BCX_BoonFavor`, `BCX_BlessingPayPct`, `BCX_BoonPayPct` | GLOB | Settings (1, 5, 10, 30, 80, 10, 20). |

| `BCX_HeatTempered/EmberForged/DragonfireBlackshieldBlade` | WEAP | Copies of `BSC_BlackshieldBlade` with Ember Smithing's tier damage (+1/+2/+3 on 10) and value (x1.3/1.7/2.2). Enchantment `BSC_EnchBladeEmber` kept. |
| `BCX_<Ember/Hearth/Bellows>EngravedBlackshieldShield`, `...Plate` | ARMO | Copies of the Blackshield Shield and Plate with a combined enchantment; value x1.5 + 100 (Ember Smithing's rule). |

## What the Codex reads from the other mods

No record of another mod is overridden. At runtime the Codex reads globals, and calls exactly two functions of other mods' scripts:

- `BSC_CompanyScript.AddRenown(Int)` on `BSC_CompanyQuest`: the company's own function, so renown, rank and promotion messages stay consistent.
- `CHT_HunterScript.BasePay(Int)` on `CHT_HunterQuest`: Contract Hunter's own base pay for a tier (level-scaled), so the bonus follows its formula.

## How the script links work

`BCX_CodexScript` polls every `BCX_PollSeconds` (5) real seconds. Papyrus single updates don't run in menus, and each poll is a handful of global reads, so the cost is negligible. Polling was chosen over editing the other mods' scripts to send events, because that would make them depend on the Codex.

**Oaths and contracts.** When `BSC_ContractActive` goes 0 -> 1, the Codex remembers which of the five `SOT_Active*` flags are set. When `BSC_ContractsDone` goes up, the oaths active now *and* at the start count as kept, and each adds `BCX_RenownPerOath` renown, 2 seconds after the payout so the company's own message comes first. A broken oath is no longer active, and Steel Oath's 72-hour cooldown keeps it from being sworn again within most contracts. A contract abandoned (active goes to 0 without a completion) clears the snapshot. A contract that was already running when the Codex was installed has no snapshot; then the oaths active at payout count.

**Daedric favor and bounties.** When `CHT_BountiesClaimed` goes up, the Codex waits a second (Contract Hunter clears the tier's open flag right after counting the claim), then finds the tier whose `CHT_Open*` flag went from 1 to 0 (Notice if it can't tell). The bonus is `floor(BasePay(tier) x CHT_PayMult x pct / 100)`, with pct from the highest of the eight `BOO_Favor*` globals: `BCX_BoonPayPct` at `BCX_BoonFavor` or more, `BCX_BlessingPayPct` at `BCX_BlessingFavor` or more, otherwise nothing. Contract Hunter's notoriety and hold standing multipliers are not applied to the bonus.

**Counters going down** (a new character, console edits) reset the Codex's memory instead of paying anything.

## ESL masters

All five masters are ESL-flagged ESPs. Skyrim SE resolves a plugin's master references by name, whether the master is loaded as a light or a full plugin; the Codex's file uses the plain master index + object ID (checked in the raw bytes: e.g. the Shield recipe's input is `01000816`, BlackshieldCompany.esp's 0x816, and the engraving effects are `0500097A/C/E`). The compatibility check simulates the runtime FormIDs of all plugins together (FE slots) and finds no collisions.

## Scaled down from the concept (documented on purpose)

- **Weapons get heat tiers, not engravings.** Ember Smithing engraves armor only (weapon enchantments need charge and soul-gem handling), so the Blade follows its weapon process: the three heat tiers, keeping its Ember Edge enchantment.
- **No retroactive bonuses** for contracts or bounties finished before installing.
- **Polling, not events.** Bonuses arrive a few seconds after the payout instead of in the same message.
- **The bounty bonus uses base pay only** (no notoriety or standing multipliers), to stay readable.
